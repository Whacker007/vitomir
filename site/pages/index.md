# Vitomir

<div class="hero"><div><p>A new engine for <em>Vampire: The Masquerade – Redemption</em>, built from scratch to play the
original v1.1 game on a modern Windows PC, with bug fixes and quality-of-life improvements.</p></div></div>

<a class="button" href="https://github.com/Whacker007/vitomir/releases/latest">Download the latest release</a>
<a class="button quiet" href="install.md">How to install</a>

Vitomir is a fan-made engine that plays the original *Redemption*, from the monastery outside Prague to the last night in
New York, on modern Windows. It keeps the original game experience intact: the same story, the same rules, the same
fights. And it fixes most of what was originally broken: the hard bugs that break the game are fixed for good, and the
rest are fixes you can switch on. It also fixes what time broke. Now with widescreen support, modern
graphics cards, old saves imported, and a new direct IP based network mode to replace the long defunct WON service.

**It needs your own copy of the game.** Vitomir comes with none of the game's files. It reads the copy you own, from
[GOG](https://www.gog.com/en/game/vampire_the_masquerade_redemption) or
[Steam](https://store.steampowered.com/app/559680), and the launcher helps import what it needs. Your copy is only read, never changed.

## What Vitomir does

- ![](assets/art/icons/feature-faithful.svg){.icon} **The original game, faithfully.** Patch 1.1's rules, numbers and behaviour, measured against the game itself.
  Its own bugs that are part of how it plays stay unless you switch a fix on. Obvious bugs that break the game, such as
  losing items, are fully fixed.
- ![](assets/art/icons/feature-widescreen.svg){.icon} **A modern screen.** Widescreen at any resolution, with the interface kept in its proportions, or the original 4:3 if
  you want to play it in the original aspect ratio. Tested and working on triple head setups.
- ![](assets/art/icons/feature-switchable.svg){.icon} **Small comforts, all switchable.** Keyboard steering (driving mode), better camera angles and zoom, quick equip,
  skipping the movies, quick buy and sell in shops, and more. Most are one box on the options page that can be turned off.
- ![](assets/art/icons/feature-movies.svg){.icon} **The game's pre-rendered cutscenes, upscaled.** Optional: the launcher can make sharper, smoother versions of the game's
  movies on your own PC, and you choose per movie which version plays.
- ![](assets/art/icons/feature-multiplayer.svg){.icon} **Multiplayer and the Storyteller, again.** Host or join over the internet or your own network, with no service
  needed to connect. No VPNs needed either: UPnP is built in. Predictive movement helps smooth out the old stuttering and
  rubber banding of the original game.
- ![](assets/art/icons/feature-launcher.svg){.icon} **A launcher that sets it all up.** It finds your copy of the game, checks it and imports it, and keeps your saves,
  settings and logs in one folder.

See [all the features](features.md).

## How Vitomir was made

This project started as a whim while on a trip. What started as just a quick install and play for a few days ended up
mushrooming into a massive effort to fully reimplement the game with major long-needed quality of life fixes, along with
some of the more egregious bugs still left after the v1.1 patch. A large part of the driver here was me learning how to
use AI to extend and expand my existing programming skills and knowledge, since my primary programming skillset was in
data structures and management, not in 3D/game development. This entire project ended up being just that, an amazing
learning experience and a real labor of love on a classic game that I spent hours playing when I was younger and have
very fond memories of.

I decided to release the platform as it stands now, with the original game fully supported and most of the features I
intend to include complete and tested. There is still a lot going on in the background, and I do intend on releasing a
reimagined take on the original campaign at some point early next year. This is a one person show, so I can't make
promises about how much or when, but understand that this is a living and evolving project, and I hope everyone loves
playing it just as much as I honestly enjoyed learning and actually making it.

## Free, and staying free
