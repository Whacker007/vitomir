## Built on

Vitomir stands on the work of these projects, each under its own licence (the release's `THIRD_PARTY.txt` lists them
in full):

- **.NET**, the runtime Vitomir runs on.
- **SDL3** and **ppy.SDL3-CS**, for the window, input, graphics and sound.
- **IKVM** and the **Eclipse Compiler for Java**, which run the game's own Java scripts.
- **DotRecast**, for finding paths; **NLayer** for MP3 sound; **BCnEncoder.Net** and the **.NET Community Toolkit**.
- **FFmpeg**, which plays the game's movies on your PC.
- **Real-ESRGAN** and **RIFE**, which upscale the movies, if you choose to.

Vitomir's typefaces, Vitomir Text, Wedge and Knife, are its own, under the SIL Open Font License.
