# The models repository's files the platform's package carries (by design: the repository is read from disk while
# developing, and the package copies what is used). One path a line, relative to the models repository (VITOMIR_MODELS_DIR
# by default: -ModelsRepo), copied into a package's People\ keeping it (tools/package.ps1 -WithPeople, tools/package-platform.ps1); a
# line starting with # is a comment. The player (PersonRecipe.Player: base_male, townsman_male, hair_collar_male, beard_short_male) and the woman
# (PersonRecipe.Woman: base_female, townswoman_female, hair_braids_female), each file with its .json and its fit, and the motions.
# The townsfolk drawn as the models repository's crowd (TownsfolkBodies): the crowd's file, and what its people wear by role and
# grooming (the townsman's tunic, the townswoman's dress, the maiden's, the monk's habit, the priest's tunic, the old man's and the
# beggar's hood; the crowd's cuts and beards). A crowd that names a file not listed here builds the townsfolk on 1.1's bodies, said once.
# The crowd as the models repository baked it, each townsperson's own folder (its body, its outfit, hair and beard
# fitted to it, its record), at the end. Not the guards' (person_00, person_02: they fight, on 1.1's bodies) nor the nun's (person_10:
# no 1.1 townsperson is drawn as her). The run-time build's files above stay: a baked person's outfit, hair and beard take what they
# cover and hide from the files they were fitted from (their .json and _fit.npz), and --crowd-built (or a folder missing) builds on them.
# The two field hands' hoods (files.hood), the four laymen added (person_11 to person_14), and the
# maps the baked files share, written once in crowd/shared/ and referred to from each file as ../shared/<file> (without them every baked
# person falls back to the run-time build: as a run of the tests found). Only the shared maps the listed people use (not the
# guards' mail and helmet).
