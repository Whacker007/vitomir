licences\ folder, in the file named on the right.

FFmpeg, which plays the game's films, is not in this package: Vitomir uses one
you install yourself, if you do.

None of the game's own files are in this package. Vitomir reads them from your
own copy of Vampire: The Masquerade - Redemption.
